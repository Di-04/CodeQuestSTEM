# CodeQuest STEM

Трёхъязычная (ҚАЗ / РУС / ENG) образовательная веб-игра и STEM-платформа.

## Состав проекта
- `index.html` — семантическая разметка, доступные области интерфейса и подключение стилей/логики.
- `styles.css` — светлая игровая тема, карта города, сетка поля робота, редактор, адаптивность для ПК и мобильных устройств.
- `app.js` — движок игры, пошаговое исполнение, 6 курсов с 3 уровнями сложности, архив ACMP, 7 STEM-проектов (детальные симуляторы «Умная теплица» и «Тёплая школа»), журнал защиты, экран учителя и локализация.
- `server.mjs` — Node.js сервер (раздача статики + защищённый `POST /hint` для ИИ-справочника).
- `hints_bank.json` — утверждённый трёхъязычный банк подсказок (ИИ выбирает только ID подсказки; произвольный ответ модели не попадает в интерфейс).
- `scripts/fetch_acmp.mjs` — скрипт дозагрузки всех 1 000 задач с `acmp.ru` в `acmp_tasks.json` при наличии сети.

## Быстрый запуск локально
Требуется Node.js 18+:
```bash
node server.mjs
```
Откройте в браузере `http://localhost:3000`.

Без запуска сервера можно открыть `index.html` напрямую — Справочник автоматически переключится на встроенный локальный банк подсказок.

## Подключение Gemini (`POST /hint`)
**Важно:** старые ключи из переписок и скриншотов считаются раскрытыми и должны быть отозваны в Google AI Studio. Никогда не вставляйте ключ в HTML, CSS, клиентский JS или репозиторий.

1. Создайте новый ключ в Google AI Studio.
2. На хостинге (Render, Railway, Fly.io, Cloud Run и др.) откройте **Environment / Secrets** и добавьте переменные:
   - `GEMINI_API_KEY` — ваш новый секретный ключ;
   - `GEMINI_MODEL` — модель (по умолчанию `gemini-2.5-flash`).
3. Локально перед запуском:
   ```bash
   export GEMINI_API_KEY="ваш_новый_ключ"
   export GEMINI_MODEL="gemini-2.5-flash"
   node server.mjs
   ```

## Синхронизация всех 1 000 задач ACMP
В сборку включены 237 проверенных записей (`0001`–`0187` и `0951`–`1000`) без генерации вымышленных данных. Чтобы загрузить остальные записи напрямую с `acmp.ru`:
```bash
node scripts/fetch_acmp.mjs
```
После этого используйте кнопку «Импорт JSON ACMP» в разделе «Миссии ACMP».
